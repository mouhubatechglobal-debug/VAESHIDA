# VAESHIDA — ARCHITECTURE TECHNIQUE

## Principe

Le projet doit être développé de manière modulaire.

## Cycle

Conception
→ Développement
→ Test
→ Correction
→ Validation
→ Documentation

## Règles

- Ne pas réécrire inutilement tout le projet.
- Ne pas supprimer une fonctionnalité existante sans raison.
- Vérifier les dépendances avant modification.
- Tester chaque système.
- Documenter les changements.
