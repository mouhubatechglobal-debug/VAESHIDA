# VAESHIDA — GAME DESIGN DOCUMENT

## Vision

VAESHIDA est un jeu Roblox RPG orienté aventure, exploration,
combat, progression et évolution du monde.

## Principes

1. Le joueur doit comprendre progressivement les systèmes.
2. Le monde doit donner envie d'explorer.
3. La progression doit être intéressante.
4. Les choix du joueur peuvent influencer certains éléments du monde.
5. Le gameplay doit rester accessible.
6. Les fonctionnalités doivent être développées progressivement.

## Prototype initial

Le premier prototype devra contenir :

- 1 petite zone ;
- 1 personnage ;
- 1 ennemi ;
- 1 attaque ;
- 1 capacité ;
- 1 quête ;
- expérience ;
- niveaux ;
- 1 boss ;
- sauvegarde.
