# VAESHIDA — ENVIRONNEMENT DE DÉVELOPPEMENT

## Machine

Projet développé principalement sous Linux Ubuntu.

## Outils principaux

- Git
- GitHub
- GitHub CLI
- Visual Studio Code
- Luau
- Roblox Studio lorsque l'environnement compatible sera disponible

## Workflow

1. Créer ou modifier une fonctionnalité.
2. Tester.
3. Corriger.
4. Vérifier Git.
5. Commit.
6. Push vers GitHub.
