# VAESHIDA

Projet de jeu Roblox RPG / aventure / exploration / combat.

## Architecture

- docs/              Documentation
- docs/design/       Game Design
- docs/technical/    Architecture technique
- docs/gameplay/     Systèmes de gameplay
- docs/story/        Univers et histoire
- docs/ui/           Interface utilisateur
- src/luau/          Scripts Luau
- assets/ui/         Ressources interface
- assets/concepts/   Concepts visuels
- assets/audio/      Audio
- ai/prompts/        Prompts IA
- ai/specifications/ Spécifications pour l'IA
- tests/             Tests
- backups/           Sauvegardes

## Méthode de développement

Architecture
→ Système
→ Test
→ Correction
→ Système suivant

## Objectif

Créer progressivement un jeu Roblox original avec :

- exploration ;
- combat ;
- pouvoirs ;
- progression ;
- quêtes ;
- factions ;
- boss ;
- événements mondiaux ;
- multijoueur ;
- monde évolutif.
